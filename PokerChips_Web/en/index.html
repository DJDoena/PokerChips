Poker Chips Calculator

This calculator figures out how to give every player an identical starting stack of the same total value, using chips from the case. It favors handing out more of the smaller denominations and fewer of the larger ones, only using a larger denomination when smaller chips alone can't reach the target. Enter the number of players, the desired stack size per player, and the maximum number of chips per value, then enter the chips available in the case (amount and value per color), and click "Calculate" to see how many chips of each color every player receives.
